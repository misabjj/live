# Untitled UI Icons Documentation

This document lists all available icons from the `@untitledui/icons` library (version 0.0.19) installed in this project.

## Installation & Usage

The library is already installed in this project:

```json
"@untitledui/icons": "^0.0.19"
```

## Import Examples

```tsx
// Individual imports (recommended for tree-shaking)
import { Home01, User01, Search01 } from '@untitledui/icons';

// Usage in components
const MyComponent = () => {
    return (
        <div>
            <Home01 className="h-6 w-6" />
            <User01 className="h-5 w-5 text-blue-500" />
            <Search01 />
        </div>
    );
};
```

## Component Properties

All icons accept standard SVG props and can be customized with:

- `className` - CSS classes for styling (Tailwind classes work great)
- `size` - Icon size (default: 24)
- `color` - Icon color
- `stroke` - Stroke width
- Standard React props like `onClick`, `onMouseOver`, etc.
